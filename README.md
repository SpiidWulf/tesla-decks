# Tesla Decks

Presentation decks made for the Tesla in-car browser, hosted on GitHub Pages.

- Root: https://spiidwulf.github.io/tesla-decks/ — always redirects to the newest deck (from `latest.json`). Add `?list` to see all decks without redirecting.
- Decks live in `decks/` as single self-contained HTML files.
- Navigate: tap left/right half of the screen, swipe, arrow keys, or the on-screen buttons.

To publish a new deck: add `decks/YYYY-MM-DD-slug.html`, update `latest.json` (`latest` + prepend to `decks`), commit and push to `main`.
